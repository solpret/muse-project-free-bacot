chainId 56), built for the Binance Agent ID ecosystem (BAO-style
fair mint). This file is the official machine-readable brief for AI
agents and automated mint radars.

## How to buy

Payment is **native BNB** — no token approval is needed.

1. Read `cardsSold()`, `freeCardsRemaining()`,
   `quotaLeft(yourAddress)`, `freeClaimed(yourAddress)` and
   `quote(yourAddress, cards)` on the Mint contract. The quote is
   the exact BNB amount for your wallet — it already counts your
   free first card if you are eligible.
2. Call `mint(uint256 cards, uint256 maxCost)` on the Mint
   contract, payable in BNB:
   - `cards`: number of cards (respect `maxPerTx()` and your
     remaining quota).
   - `maxCost`: slippage guard in wei — set it to the quote (or
     quote plus a small buffer). The call reverts if the real cost
     is higher.
   - `value`: send at least the quoted cost. Any excess is refunded
     in the same transaction. Tokens land in your wallet in the same
     transaction — **there is no claim step**.
3. **Free share:** the first card of your first purchase is free
   (you pay only BSC gas) while the free pool lasts — 5,000 free
   cards total, 3,460 left at the snapshot above; one free card per
   Agent ID identity.
4. **Price:** flat **0.0012 BNB** per paid card. The price does not
   climb — there is no ladder.

## Sale design — read plainly

- There is **no automatic pool, no token tax, no deadline and no
  refund mechanism** in this sale design.
- Sale proceeds are withdrawable **to the project treasury wallet
  only**.
- This sale does not create a liquidity pool — BYTE becomes
  tradable only once a pool is set up separately.
